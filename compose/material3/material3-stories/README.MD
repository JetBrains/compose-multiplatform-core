**To run in a browser:**

Kotlin/Wasm:
```shell
./gradlew :compose:material3:material3-stories:wasmJsBrowserStoriesDevelopmentRun
```

Kotlin/Wasm distribution:
```shell
./gradlew :compose:material3:material3-stories:wasmJsBrowserStoriesProductionExecutableDistribution
```


**To run on desktop:**
```shell
./gradlew :compose:material3:material3-stories:desktopStoriesRun
```
